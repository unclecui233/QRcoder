# 二维码分析与生成器

最近删除一些不需要的软件时，看到了之前的一个古老的QR识别软件，其实我很久没用过了，一直在用在线的，后面感觉不如直接删了自己写一个（

就有了这个赤石作品，实现了推拽识别，复制粘贴识别，文件上传识别，还可以自动识别除了QR码以外的大部分二维码和一维码，只做了常见的适配，没有做一些奇怪的编码

主要靠缝合其他的编码方式，前端界面是AI写的，顺手让AI写了个打包

## 运行

源码运行：`python main.py [图片路径]`

也可以打包后直接运行exe

## 打包

```
pyinstaller qrcoder_app.spec.py
```

三平台各自在本机构建（Windows .exe / macOS .app（加 `--windowed` 同 spec） / Linux 可用 PyInstaller 产物或 AppImage 封装）。
